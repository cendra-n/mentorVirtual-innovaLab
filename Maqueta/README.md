# Archivos de Prueba

Este directorio contiene archivos utilizados para testing y desarrollo del proyecto Mentor Virtual Adaptativo.

## Contenido

- PDFs de prueba para el módulo Tutor RAG
- Datos de ejemplo para testing de endpoints
- Scripts de prueba varios

## Uso

Los archivos de este directorio **no deben subirse a producción** y están excluidos del deploy.
